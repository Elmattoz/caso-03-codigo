## 📋 Descripción del Proyecto

Este sistema en Python permite la gestión y administración de un parqueadero en tiempo real. Entre sus funcionalidades principales se encuentran:
* **Entrada y registro de vehículos:** Captura de placa, tipo de vehículo (automóvil, motocicleta, etc.) y hora de ingreso.
* **Cálculo de tarifas:** Liquidación del costo total según el tiempo de permanencia y el tipo de vehículo.
* **Salida de vehículos:** Control de cupos disponibles y liberación de espacios.
* **Consultas y reportes:** Visualización del estado actual de ocupación del parqueadero.
